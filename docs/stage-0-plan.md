## 验收目标

独立 Windows Release 程序显示真实骨骼模型，透明置顶；身体可点击/拖动，空白跨应用穿透，不抢键盘焦点；共享待机和挥手动作在 VRM/GLB 上播放；验证眨眼、张嘴和次级运动；可从托盘退出且无残留进程。没有实测的项目明确记为未验证。

## 接口约定

原生类 `PetWindowBridge`：`configure(hwnd: int) -> bool`，`set_interactive(bool)`，`get_cursor_position() -> Vector2i`，`get_dpi_scale() -> float`，`is_left_button_down() -> bool`，`begin_capture() -> bool`，`end_capture()`，`has_capture() -> bool`，`poll_tray_action() -> int`，`shutdown()`。

托盘动作：0 无，1 显示/隐藏，2 恢复位置，3 下个角色，4 待机/挥手，5 退出。角色窗口以物理桌面像素与 Win32 交互；逻辑尺寸通过 DPI 缩放转换一次，避免双重缩放。

模型准备产物说明独立写入 `docs/reports/stage-0/assets.md`，包含模型及动作路径、骨骼映射、比例、静止姿态、口型/表情能力及许可来源。

## 关键测试

- 状态机：按下起始于身体、拖出窗口后释放、捕获丢失、隐藏/退出收尾、轻点不移动。
- 命中：旋转/抬手后身体区域随骨骼移动，明显空白返回 false，负屏幕坐标不影响判定。
- 动作：同源 idle/wave 驱动 VRM 与 GLB；不同动作的骨骼旋转和渲染姿态确实变化；不同体型不能靠名字匹配判为兼容。
- 发布：编辑器关闭、中文和空格路径启动、DLL 加载、托盘退出，启动失败有可读日志。
- 实机：桌面/记事本/资源管理器/浏览器下穿透，不激活角色窗口；125% 当前缩放实测，其余缩放和多屏只在实际测过后标记通过。
