# Pet3D 阶段 0 本地技术验证包

双击 `Pet3D-Stage0.exe`。角色窗口透明置顶，不应夺走其他程序的键盘焦点。

- 在角色身体上按住鼠标左键拖动；轻点触发挥手。
- 启动与“恢复位置”会把角色放到工作区右下角，鞋底贴近任务栏上沿。拖动边界按可见角色计算，透明窗口空白可超出屏幕；靠边后会随待机/挥手保持贴边。
- 角色周围的明显空白区域应能点击下面的程序。
- 在 Windows 托盘找到 Pet3D 图标，右键菜单可隐藏/显示、恢复位置、切换测试角色、播放动作和退出。
- 紧急恢复位置：`Ctrl+Alt+F10`；紧急退出：`Ctrl+Alt+Q`。快捷键注册冲突时仍可使用托盘菜单。
- 这是阶段 0 验证原型，尚未包含聊天、记忆、语音合成、完整桌面行为或自动保存位置。

目录必须完整保留，程序依赖同目录 PCK 和 DLL。程序日志通过 Godot 的用户数据目录保存；本轮验收记录见工程 `docs/reports/stage-0/`。

开发者从工程根目录执行 `python tools/build_stage0.py`，依次重新导入、运行测试、导出 Windows Release；原生模块的构建命令见 `native/`。

测试角色仅用于本地开发验证，正式主角色尚待确认。素材和依赖来源见 `THIRD_PARTY_NOTICES.md`。本包不包含受限制的 VRM 1.0 参考模型。
