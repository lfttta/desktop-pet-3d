# Pet3D 桌面宠物（Godette）

便携包位于 `dist/stage-2-godette`，请保留整个目录。

- 双击 `Pet3D.exe` 启动：透明置顶、逐像素命中（空白处鼠标穿透）、身体可拖动。
- 左键点一下身体：停下当前动作并挥手，同时从台词库随机说一句；按住拖动：角色跟着光标摆动，松手后带速度下落，落回工作区底边。
- 空闲时自主行动：待机、随机播一个短动作，或沿工作区底边来回走一段。走到边缘会停住，不会走出屏幕；行动中拖拽或点击立刻打断。
- 右键托盘图标 →「动作」有 8 个分类共 65 个动作可手动选播；桌宠自己闲逛时只用基础 7 个（待机、行走、转身、挥手、被提起、下落、恢复）。
- 托盘：显示 / 隐藏、恢复位置、待机 / 挥手、动作、设置、聊天、退出。热键 `Ctrl+Alt+F10` 恢复位置，`Ctrl+Alt+Q` 退出。
- 设置窗口分 7 页：基础、AI、记忆、表达、主动、成长、用量与诊断。基础页可关掉自主行为、开关「登录 Windows 后自动启动」、选安静时长与待机 / 拖拽 / 隐藏三档帧率；AI 页可填称呼、单次回复上限、重试次数、是否朗读、是否把提示词写进诊断日志。
- 聊天窗口接入本机后台服务；填好接口地址、模型名和 API Key 即可对话。回复会以头顶气泡出现，并带表情与动作；点一下头顶气泡，原处弹出回复条，打完回车直接发送，不用先开聊天窗口（回复条右侧「聊天」才开完整窗口）。气泡与问候都能在设置 →「主动」页的「气泡与问候」小节里关掉。
- 它想记住的事不会直接落库：回复下面列出候选，点「记住」才写入，点「忽略」只在这一条消息里收起来。设置 → 记忆页可以看、纠正、归档已记住的内容。

双击 `Preview.cmd`（`--review`）打开动作与表情预览：动作列表、速度、视角、暂停、自然/开心/难过表情，以及本地合成测试音频。音频播放时嘴部按播放时间开合。

## 行为边界

本包只做「沿工作区底边」的行走：脚底不动的工作区上沿、任意高度漫游、攀爬都未实现。被拖动到空中松手会落回底边；若存档里角色的脚底本来就在底边之上（手工改过 `placement.y`），它会原地待机，不会自己走——因为行走会把脚底钉回底边，那会变成一次瞬移。

未接入：截屏视觉、视线跟随。语音朗读的代码已经有了（Windows 系统语音合成），但**默认关闭**：合成跑在服务线程上，长句子会挡住其它请求，等异步化做完再默认开。需要的话在设置 → AI 页打开「朗读回复」。

主程序使用同目录内的后台服务，运行不依赖全局 Python。用户设置默认保存在 `%LOCALAPPDATA%/Pet3D`，可通过 `-- --data-dir=<绝对路径>` 指定独立数据目录。同一时间只允许一个实例。

## 开发与构建

Python 版本为 3.13.14；项目使用 `.venv`，构建依赖版本见 `requirements-dev.txt`。

```powershell
# 已有环境：完整单角色构建和验收，默认复用已验证缓存
.\.venv\Scripts\python.exe -B tools/build_stage2.py

# 仅当动作源变化时重建资产，需要本机 Blender 和原 FBX 目录
.\.venv\Scripts\python.exe -B tools/build_stage2.py --rebuild-assets
```

构建从当前 `app` 生成暂存包，跑完 Godot 测试、pytest、原生断言、导出、整包资源检查与桌面验收后输出到 `dist/stage-2-godette`。资产重建先写入 `build/stage2/godette.tres`，通过与原版待机/挥手的逐帧对照后才替换运行缓存。原缓存 `app/motions/cache/godette.tres` 仅用于回归对照，不装入新包。

实际桌面验收会短暂移动鼠标测试拖动与回落，随后恢复鼠标位置，并进行待机 / 重复动作观测。详细日志、截图和性能数据在 `build/stage2/reports`。

工程内的阶段范围见 `docs/stage-2-plan.md`（打包与资源）与 `docs/stage-3-plan.md`（行为与行走），完成记录见 `docs/reports/`。原阶段一包、备份和多角色实验资料保留；新包只装配 Godette。第三方来源及署名见 `THIRD_PARTY_NOTICES.md`。
