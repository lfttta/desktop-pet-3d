1. **[P2] Establish passthrough before synchronous character loading.** [main.gd:41](D:/danjigame/3D-pet-gtpdo/prototypes/stage0/scripts/main.gd:41) loads and instantiates the first character before constructing/configuring the native bridge at lines 48–61. During a cold model load the window therefore has no app-established passthrough policy, so its initially blank rectangle can intercept desktop clicks. The subsequent held-button priming only prevents taking over the drag after loading; it cannot deliver those earlier clicks to the application underneath.
