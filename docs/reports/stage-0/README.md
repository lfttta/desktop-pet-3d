## 已实现

- Godot 4.7.2 标准版，Mobile + D3D12 透明置顶角色窗口；窗口创建时禁止获取焦点，运行时由独立 Win32 桥接管理命中/穿透和捕获。
- 身体区域轻点挥手、按住拖动；通过投影后的骨骼胶囊区域判断命中，明确空白可设为跨进程穿透。拖动期间保持捕获，释放/丢失捕获/隐藏都收尾。
- Godette（VRM 0.x）与剑士（GLB）两个测试角色，复用用户 `Idle.fbx` 与 `Waving.fbx` 作为动作源；每模型动作缓存由工具生成，运行时不搬动模型骨骼层级。
- 角色切换、独立眨眼/张嘴通道、VRM 原生弹簧骨；GLB 无表情/弹簧骨时如实保留能力差异。
- 托盘显示/隐藏、恢复位置、换角色、待机/挥手和退出；独立 Windows Release 导出目录。

## 本轮界面验证中止原因

Windows Computer Use 的自动检查无法可靠识别当前浏览器 URL，因而停止本轮界面自动化。收到结果后停止所有应用输入操作，没有改用其他输入通道绕过检查。代码、文件、离线构建与无界面测试继续完成。

记事本启动尝试也没有获得可操作窗口；没有因此安装系统组件或更改系统设置。
