# Pet3D 桌宠 —— 使用说明

双击 **`Pet3D.exe`** 即可启动。不需要安装 Godot，也不需要安装 Python。

## 这是什么

一只 3D 桌面宠物（角色 Godette），会待在屏幕边上待机、自己走一段、被拖动、挥手，可以聊天、记住你说过的话。整个程序就在这个文件夹里，拷到别的 Windows 电脑上同样能用。

## 怎么用

| 操作 | 效果 |
|---|---|
| 双击 `Pet3D.exe` | 启动桌宠 |
| 左键按住拖动 | 移动桌宠位置，松手后落回桌面底边 |
| 左键点一下 | 桌宠挥手 |
| 不动它 | 它会自己待机、随机演个小动作，或沿屏幕底边来回走一段 |
| 右键托盘图标 → 动作 | **从 65 个动作里挑一个让桌宠表演** |
| 右键托盘图标 → 聊天 | 打开聊天窗口 |
| 右键托盘图标 → 设置 | 改称呼、大小、显示器、聊天配置 |
| 右键托盘图标 → 显示/隐藏 | 收起或叫回桌宠 |
| `Ctrl+Alt+F10` | 找回桌宠（位置跑到屏幕外时用） |
| `Ctrl+Alt+Q` | 退出 |

托盘图标在任务栏右下角的通知区域。

## 65 个动作

右键托盘图标 →「动作」，有 8 个分类：

- **基础动作**：待机、行走、转身、挥手、被提起、下落、恢复
- **跳舞**：跳舞、霹雳舞、扭臀舞、江南Style、嘻哈舞、玛卡瑞纳舞、萨尔萨舞、旋转
- **情绪**：开心、大笑、兴奋、欢呼、哭泣、难过待机、生气、害怕、惊讶、无聊、害羞、眩晕待机
- **互动**：点头同意、鼓掌、飞吻、敬礼、站立问候、指向、耸肩、挑衅、大喊、挥摆
- **日常**：喝水、坐下、坐姿、睡觉、打哈欠、思考、祈祷、伸展颈部、四处张望、紧张张望、唱歌、跳跃
- **行走移动**：奔跑、疲惫奔跑、老人行走、持物行走、抱箱行走、攀爬、爬梯子、翻墙上行、翻墙下行
- **道具动作**：搬运、抱箱待机、按住、站立取弓
- **姿态**：躺姿点头、躺姿咳嗽、胜利

点哪个，桌宠立刻演哪个。桌宠自己闲逛时只用「基础动作」那 7 个。

自己走动时会在屏幕底边来回，走到边缘就停住，不会走出屏幕；这时拖它或点它，它会立刻停下回应你。把它拖到半空松手，它会落回底边。上下左右四边里目前只走底边，上边和半空漫游还没做。

## 聊天配置

第一次用聊天需要填 API 配置：右键托盘图标 → 设置 → AI 页，填接口地址、模型名和 API Key。

默认值是 DeepSeek（`https://api.deepseek.com`、`deepseek-chat`）。用别的 OpenAI 兼容服务也可以，改地址和模型名就行。

设置窗口里还有「记忆」「表达」「主动」「成长」「用量与诊断」几页：记忆页看和管聊天记住的内容，表达页管台词，主动页管它自己找话说，成长页看人格变化，用量页看 token 消耗和诊断导出。

不填也能用——桌宠会正常待机、拖动、演动作、自己走，只是不能聊天。

## 数据存在哪

设置、聊天记录、记忆都存在：

```
%LOCALAPPDATA%\Pet3D\
```

包含 `settings.json`（设置）、`pet.db`（聊天记录与记忆）、`service.lock`（防止重复启动的锁）。删掉这个目录 = 恢复出厂状态。API Key 用 Windows DPAPI 加密保存，不在明文配置文件里。

## 换电脑

整个文件夹拷过去就能用。目标电脑要求：

- Windows 10 / 11，64 位
- 通过 DirectX 12 或 Vulkan 可用显卡驱动（近年显卡都满足）

不需要装 Godot、Python 或任何运行库。

## 常见问题

**双击没反应 / 闪一下就没了**
看 `%LOCALAPPDATA%\Pet3D\` 下有没有生成文件；如果之前有旧版本在跑，先退出（`Ctrl+Alt+Q`）再启动。同一时间只能有一个实例。

**桌宠跑到屏幕外了**
按 `Ctrl+Alt+F10`，或右键托盘图标 →「恢复位置」。

**点了动作没反应**
确认点的是菜单里的项。如果某个具体动作卡住，退出重启一次；仍不行请记录动作名反馈。

**桌宠自己走的时候位置乱跳**
不应该发生。行走位移按整圈动画量化，走完才落点。若看到瞬移，请记录当时是否刚拖动过、是否改过 `settings.json` 里的 `placement`。

**聊天发不出去**
先检查设置里的接口地址、模型名、API Key 三项。用「测试连接」按钮验证。断网或配置错误时桌宠本体仍然可用。

**任务栏找不到托盘图标**
Windows 会把新图标折叠进「^」里。拖出来固定住即可。
