## 2. 本阶段范围

只交付一个 Godette 桌宠：七类身体动作、可靠打断与复位、基础表情/眨眼/简单口型，以及可直接启动的单角色便携包。

- 保留现有 Godot、VRM/MToon、Windows 窗口桥和后台服务。
- 保留 Godette 原模型、蒙皮、骨骼层级和已验证的适配参数。
- 设置和托盘不再提供无意义的角色选择；仍保留称呼、缩放、显示器等已有设置。
- 新包只包含 Godette 所需的模型、纹理、配置和缓存。纸片剑士继续排除。
- 暂缓 Alicia、士兵及其他角色的适配、角色导入、热切换、通用角色管理和多角色测试矩阵；保留历史资料供后期复用。
- 随机行走、松手速度、重力、抛落和落地物理属于阶段三；本阶段的行走、提起和下落是动作资源及调用接口。
- AI、TTS 接入、高级视线跟随、复杂情绪组合和音素级唇形留到后续，不作为这轮简化版的前置条件。

## 3. 简化后的流程

`动作源 → Godette 动作缓存 → 一个动作控制器 → 主工程 → 单角色便携包`

保留一份 Godette 配置、一份七动作缓存和一个构建入口。不新增多角色框架，也不为未来换角色预先重写运行架构。现有动作源和映射作为资源保留，后期需要时再扩展。

离线转换和烘焙只在资产改变时需要运行；日常调试直接使用已验证缓存。继续通过暂存输出、验证后替换的方式保护正常版本，不让试验结果直接覆盖正在使用的缓存。

## 5. 然后完成动作与基础表现

### 身体动作

| 动作 | 采用的已有成果 | 结束或释放规则 |
|---|---|---|
| `idle` 待机 | 原 Idle，保留身体轻微摆动 | 循环 |
| `walk` 行走 | 原 Walking，剥离累计水平位移 | 循环；暂不驱动窗口行走 |
| `turn` 转身 | 公共源短踏步，角色节点统一控制左右转向 | 完成转向后回待机，避免重复旋转 |
| `wave` 挥手 | 原 Waving | 单次结束回待机 |
| `pickup` 被提起 | 已制作的悬垂姿态 | 保持至释放 |
| `fall` 下落 | Falling 空中姿态 | 保持至后续状态接管 |
| `recover` 恢复 | 已制作的落地缓冲姿态 | 完成后回待机 |

- [ ] 统一动作请求、优先级和取消；旧回调不能覆盖新动作，连续点击或打断不残留姿势。
- [ ] 明确暂停、隐藏、恢复和退出时的动作处理；复位时恢复可用待机状态。
- [ ] 保留当前动态边界修复，检查转身、混合和抬手时的裁切及贴边。相机不随每帧动作大小缩放。
- [ ] 开发预览只保留动作、播放/暂停、速度、转身方向和视角控件。

### Godette 基础表现

- [ ] 从实际 VRM 元数据确认并接入 neutral、happy、sad 等确实存在的表情；缺少的表情不伪造为已支持。
- [ ] 自动眨眼、情绪与嘴部由明确的通道管理，避免多个更新函数互相覆盖权重。
- [ ] 用一段本地测试音频及振幅包络实现简单嘴部开合，按实际播放位置采样；暂不要求联网 TTS 或五元音识别。
- [ ] 暂停、停止、音频结束、隐藏和退出时嘴部归零；恢复后按当前播放位置更新。

身体动作先通过，再加入面部控制；只调整当前暴露的问题，不同时重写模型导入、窗口桥和后台服务。
