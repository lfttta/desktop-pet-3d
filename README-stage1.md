# Pet3D 阶段 1 本地便携版

双击 `Pet3D.exe` 启动。程序会在同目录启动自己的后台服务，不依赖系统 Python；整个 `stage-1` 目录需要一起保留。

- 角色窗口透明置顶，不抢其他程序的键盘焦点；身体可拖动，透明空白区域可点击下层窗口。
- 托盘菜单可打开设置、聊天占位窗口、找回角色、隐藏/显示、切换角色、播放动作和退出。
- 设置窗口可保存称呼、角色、大小与显示器；位置会自动保存并在重启后恢复。
- 同一用户数据目录只运行一个实例。重复启动会唤回已经运行的角色。
- 后台服务异常退出时会自动恢复一次；主程序退出或被终止时，自有服务会随之结束。
- 本阶段动作仍为待机和挥手。行走、转身、拾取、跌落和恢复等动作在阶段 2 接入。
- 聊天窗口本阶段只显示准备状态，尚未连接 AI、人格、记忆或语音功能。

默认设置和数据库保存在 `%LOCALAPPDATA%\Pet3D`。紧急恢复位置使用 `Ctrl+Alt+F10`，紧急退出使用 `Ctrl+Alt+Q`；快捷键冲突时可使用托盘菜单。

测试角色和依赖来源见 `THIRD_PARTY_NOTICES.md`。阶段 1 的自动化验收记录位于工程 `docs/reports/stage-1/`。
